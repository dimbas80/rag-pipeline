## Реализация

### 1. `_extract_headings_from_json(pages)` → list[dict]

5-правил алгоритм (ADR-8):

1. **Regex**: `^(\d+(?:\.\d+)*)\.\s` — номер раздела всегда
   заканчивается точкой перед пробелом («3. ЗАЩИТА», «3.2.1.
   Молниеприемники»; «200 кА» — не матчится).
2. **Длина**: `len(text) < 100` И слов < 10.
3. **Левый край**: `rel_x = x_left / page_width < 0.50`.
4. **Один блок на строке**: на той же странице и Y-координате
   (±15px) нет других блоков — ключевой фильтр против ячеек таблиц.
5. **Уровень**: глубина номера: «3» → level 1, «3.2» → level 2,
   «3.2.1» → level 3, «3.2.1.1» → level 4.

Возвращает `[{"page", "y", "level", "number", "text", "full_text"}, ...]`.
При `pages=None` или `[]` возвращает пустой список.

### 2. `_apply_headings_to_md(md_text, headings)` → str

Для каждого heading находит в md_text `**{full_text}**` и заменяет на
`{'#' * (level+1)} {full_text}` через `re.sub(count=1)` — дубликаты в
оглавлении остаются жирным текстом. `re.escape()` защищает спецсимволы.
При пустом `headings` возвращает md_text без изменений.

### 3. Интеграция в `process_file()`

После вызова `parse_yandex_json_to_md()` (и сохранения raw.md), до
`run_script_postprocess()`:

```python
headings = _extract_headings_from_json(pages)
if headings:
    md_text = _apply_headings_to_md(md_text, headings)
    log.info(f"  Заголовков заменено: {len(headings)}")
else:
    log.info("  Заголовки не найдены — MD без изменений")
```

## Тесты

Новый файл `firmware/src/test_headings.py` (20 тестов):

- `_extract_headings_from_json`: простое извлечение, глубина уровней
  (до 4), regex «200 кА» не матчится, точка после номера обязательна,
  длина/слова, rel_x порог (0.45 → match, 0.60 → нет), один блок на
  строке (±15px, граница >15px), пустые pages/None/без blocks.
- `_apply_headings_to_md`: базовая замена, маппинг уровней
  (1→##, 2→###, 3→####, 4→#####), count=1 сохраняет дубликаты,
  re.escape спецсимволов, пустой список/None → без изменений, нет
  совпадения → без изменений.
- Интеграция `process_file()`: md с **-заголовком до
  `run_script_postprocess()`; без заголовков md не меняется.

## Известные ограничения

- Заголовки, которые рендерятся не как `**...**` (например, элементы
  списка `- 2.3.2. ...` или `LAYOUT_TYPE_LIST`), не заменяются — это
  соответствует ADR-8: заменяются только жирные заголовки.
- Порог rel_x 0.50 и tolerance Y 15px взяты из ADR-8 (валидированы
  архитектором на тестовом документе).
