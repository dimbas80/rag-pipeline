# Implementation report — t_0d305a35

## Summary
Исправление дублирования таблиц в `ai_postprocess()` по ADR-007: два
компонента — section-aware chunking в `_chunk_text()` и обновление промпта
в `config_ai.yaml`.

### 1. `_chunk_text()` — двухфазный section-aware chunking (`firmware/src/pipeline.py`, ~строка 2549)

**Фаза 1 — партиционирование по границам разделов:**

```python
SECTION_BOUNDARY_RE = re.compile(
    r"^(?:#{1,5}\s+\d+(?:\.\d+)*\.\s|\*\*\d+(?:\.\d+)*\.\s+[^*]+?\*\*)"
)
```

Захватывает: `**1. ВВЕДЕНИЕ**`, `**2.1. Термины и определения**`,
`**3.2.1.1. Общие соображения**`, `### 4.5. Заземление`,
`#### 4.7.1. Меры защиты`, `## 4. ЗАЩИТА`.

НЕ захватывает: `**Исходные данные о здании и окружении**` (нет номера),
`*Таблица 4.3*` (подпись), `| **200 кА** |` (ячейка таблицы — номер без
точки), обычный текст.

Секция = строки от заголовка (включительно) до следующего заголовка.
Текст до первого заголовка — «преамбула», отдельная секция (первый чанк).

**Фаза 2 — сборка чанков из целых секций:**
- секции добавляются в текущий чанк, пока `len(current) + len(section) + 2 <= max_chars`;
- секция > `max_chars` разбивается через `_split_oversized_section()`
  (старая логика `_chunk_text()`, сохранена без изменений как отдельная функция);
- если границ разделов не найдено — fallback целиком на
  `_split_oversized_section()` (старая логика).

## Known limitations
- Экзотические форматы заголовков (без номера, без точки, другие маркеры)
  регэкспом не покрываются — документ целиком уходит в fallback (старую
  логику), это не регрессия.
- Если секция-гигант не содержит пустых строк (один параграф > max_chars),
  `_split_oversized_section()` не может её разбить — такой параграф
  остаётся одним чанком (как и в старой логике).

## Deviations from architecture
1. **Регэксп ADR-007 как литерально записан не работает**: `\d+(?:\.\d+)*\s`
   не матчит собственные примеры ADR (`## 4. ЗАЩИТА`, `**1. ВВЕДЕНИЕ**`),
   потому что после номера идёт точка. Использован регэксп из текста задачи
   (`**N. ...**`, `**N.N. ...**`, `### N.N. ...`, `#### N.N.N. ...`) с
   обязательной точкой (`\.`), что дополнительно исключает `**200 кА**`.
2. Диапазон `#{1,5}` вместо `#{1,4}` из ADR: в рабочем дереве уже
   реализован ADR-8 (`_apply_headings_to_md`), который рендерит заголовки
   уровня 4 как `#####`. Расширение не ломает ничего, т.к. строка из 5
   `#` с номером — всегда заголовок.
3. `config_ai.yaml` в рабочем дереве содержит незакоммиченные изменения
   предыдущих задач (провайдер provod/gemini, ADR-8 и др.) — не трогал их;
   изменил только блок `ai_postprocess.prompt`.
