# Implementation report — t_5c043e40

## Задача

Усилить промпт `ai_postprocess` в `firmware/src/config_ai.yaml`: добавить жёсткое правило
in-place редактирования таблиц, чтобы модель не собирала исправленные таблицы в конце
документа.

Внесено ровно три изменения в секцию `ai_postprocess.prompt`:

### 1. ГЛАВНОЕ ПРАВИЛО (после роли)

Сразу после строки «Ты — редактор технических текстов…» добавлен приоритетный блок:

```yaml
    ГЛАВНОЕ ПРАВИЛО: все таблицы должны оставаться на своих исходных местах в тексте.
    Ты редактируешь существующие таблицы in-place — сравниваешь с эталоном,
    исправляешь ошибки, дополняешь пустые ячейки, НО НЕ перемещаешь таблицу
    ни на одну строку. Каждая таблица остаётся между теми же абзацами,
    в том же разделе, что и в исходном Markdown-файле.
```

### 2. СВЕРКА ТАБЛИЦ С VISION-ЭТАЛОНОМ (уточнение перед правилом 14)

Между заголовком секции и правилом 14 добавлено разъяснение, что «Эталонные таблицы» —
это копии из картинок (могут содержать ошибки), их можно использовать ТОЛЬКО для сверки
и дополнения ячеек существующих таблиц, а новые таблицы в конце документа создавать нельзя:

```yaml
    Таблицы НЕЛЬЗЯ перемещать. Блок «Эталонные таблицы» содержит копии таблиц
    из картинок — они могут содержать ошибки. Используй их ТОЛЬКО для сверки
    и дополнения данных внутри ячеек существующих таблиц. НЕ создавай новые
    таблицы в конце документа.
```

### 3. ЧТО НЕЛЬЗЯ (дублирующая короткая строка)

Перед существующей строкой про неперемещение таблиц добавлена короткая жёсткая формулировка
(существующая строка сохранена без изменений):

```yaml
    - НЕ перемещай таблицы — каждая таблица редактируется строго in-place
```
