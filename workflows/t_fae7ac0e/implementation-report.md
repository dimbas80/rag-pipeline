# Implementation report — t_fae7ac0e

Добавление логирования в `extract_images_from_pdf()`: результат по каждому picture + итоговый summary.

## Сводка

`firmware/src/pipeline.py`

### 1. `extract_images_from_pdf` — лог по каждому picture

После вызова `_crop_and_save_image` для каждого picture теперь пишется результат:

- Успех: `log.info("  fig_N (стр.P): извлечено (WxH)")` — реальные размеры сохранённого
  pixmap (`pix.width` × `pix.height`, с учётом DPI-масштаба 2.0).
- Провал: `log.warning("  fig_N (стр.P): ПРОПУЩЕНО — rect за границей страницы")`, если
  `fitz_rect` не пересекается с `page.rect`, иначе
  `log.warning("  fig_N (стр.P): ПРОПУЩЕНО — ошибка вырезки")`.
- Картинка без `bbox.vertices` (< 4 вершин): `log.warning` «ПРОПУЩЕНА, fig_N не присвоен»
  (раньше молча `continue`).

### 2. Итоговый summary

Вместо `log.info("  Сохранено изображений: N")`:

- `log.info("  Извлечено: 3/13 (fig_1, fig_12, fig_13)")` — при частичном извлечении;
- `log.warning("  Пропущено: 10 (fig_2, fig_3, ...)")` — при наличии пропусков;
- без пропусков: `log.info("  Извлечено: 13/13")`.

`total` считается по `fig_counter`, а не `len(pictures)`: картинки без `bbox.vertices`
(< 4) не получают `fig_N`, поэтому `len(pictures)` давал бы «фантомные» номера в списке
пропущенных. При `saved == 0` строка «Извлечено» пишется без списка fig (иначе вышло бы
`fig_` с пустым списком).

### 3. `_crop_and_save_image`

- Перед `page.get_pixmap()` добавлен `log.debug("    crop rect=Rect(...) -> <path>")` с
  координатами rect.
- Возвращает сохранённый `fitz.Pixmap` вместо `bool` (нужно для реальных размеров
  WxH в логе) или `None` при ошибке. Единственный вызывающий код — строка 1447 —
  обновлён (`pix is not None` вместо `success`).
- В `except` добавлена чистка 0-байтного «фантома»: `pix.save()` успевает создать
  пустой файл перед исключением (проверено на rect за границей страницы: MuPDF
  выбрасывает `code=4 Invalid bandwriter header`), и в папке оставался `fig_N.png`
  нулевого размера. Теперь файл удаляется через `output_path.unlink(missing_ok=True)`.

## Ограничения

- Ветка «ПРОПУЩЕНО — ошибка вырезки» (когда rect внутри страницы, но `get_pixmap`/
  `save` упали) не воспроизведена вживую — в текущих данных MuPDF падает только на
  rect за границей. Ветка тривиальна и покрыта кодом (else от intersects).
- Pyright (LSP) продолжает ругаться на строковые аннотации `"fitz.*"` — это
  пре-существующее поведение файла (PyMuPDF без стабов); рантайм и py_compile чисты.

## Отклонения от архитектуры

Нет. Изменения только внутри `extract_images_from_pdf` / `_crop_and_save_image`,
контракт возврата `_crop_and_save_image` расширен с bool на pixmap (единственный
вызывающий код обновлён в этом же коммите).
