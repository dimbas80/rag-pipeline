# interface_RAG

Интерфейс для RAG (Retrieval-Augmented Generation). Координируется Hermes Orchestrator.

## Workflow

Discovery
→ Software Architecture
→ Implementation
→ Review
→ Integration

## Source of Truth

- Требования: `docs/requirements/`
- Архитектура ПО: `docs/software/`
- Исходники: `firmware/src/`
- Тесты: `tests/`
- Ревью: `docs/review/`

Не приступать к реализации до утверждения архитектуры ПО.
