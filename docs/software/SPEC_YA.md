# Задание на паплайн конвертации pdf, docx в markdown через Yandex AI Studio. Vision OCR
за основу можно взять скрипты из проекта Create_markdown
## 1. Работа 
1. Паплайн должен принимать на вход или отдельный файл или папку с файлами для обработки. В качестве выхода должна устанавливаться папка с местом расположения файла(папки) входа с подпапкой Markdown/. В подпапке Markdown/ должны создаваться папки с именем обрабатываемых файлов.
2. Паплайн должен использовать  Vision OCR скилл yandex-ocr 
## 2. Постобработка
1. Для пост обработки полученного результата от Vision OCR использовать функционал из проекта Create_markdown. Для получения итогового md должен использоваться json полученный от Vision OCR 
2. Задачи постобработчика:
- Исправить OCR-артефакты в тексте (разбитые слова, лишние пробелы)                                                                        
- Исправить структуру документа                 
- Блоки формул обернуть equation.text в $$
- Очистка LaTeX пробелы в числах, \mathsf → текст, добавить перед \^{...} пробел: например 90^{\circ} → 90 ^{\circ}
- Конвертация таблиц HTML → Markdown
- Объединенные ячейки заголовка разбивать на отдельные ячейки. Текст объединенных ячеек должен быть в заголовке каждого столбца
- пример
 *Таблица 7.6 — Коэффициенты спроса для рабочего освещения*

| | Организации, предприятия и учреждения | $K_{\text{с.о}}$ при установленной мощности до 5 кВт | $K_{\text{с.о}}$ при установленной мощности 10 кВт | $K_{\text{с.о}}$ при установленной мощности 15 кВт | $K_{\text{с.о}}$ при установленной мощности 25 кВт | $K_{\text{с.о}}$ при установленной мощности 50 кВт | $K_{\text{с.о}}$ при установленной мощности 100 кВт | $K_{\text{с.о}}$ при установленной мощности 200 кВт | $K_{\text{с.о}}$ при установленной мощности 400 кВт | $K_{\text{с.о}}$ при установленной мощности св. 500 кВт |
| :---: | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | Гостиницы, спальные корпуса и административные помещения санаториев, домов отдыха, пансионатов, турбаз, оздоровительных лагерей | 1 | 0,8 | 0,7 | 0,6 | 0,5 | 0,4 | 0,35 | 0,3 | 0,3 |
- Объединить таблицы по следующим признакам: одинаковый заголовок (если заголовок одинаковый, но название таблицы разное не объединять), название следующей таблицы начинается со слов "Продолжение...", "окончание..", следующая таблица не имеет заголовка.
- Примечания и сноски под таблицами (строки вида "П р и м е ч а н и е ..." или "Примечание ...") выделить цитатами: > Примечание ... Если примечание или сноска в ячейках таблицы, то вынести из таблицы и выдели цитатой
- Форматирование подписей  Таблица N, Рис. N
### Вставка изображений
- Из исходного pdf или docx нужно найти и вырезать все изображения по координатам, полученным из json. Изображения сохранять а папку image/ рядом с итоговым md
- Переименование файлов изображений понятные fig_N
- в итоговой md вставить ссылки на изображения согласно координатам из json
- Подписи под изображениями (строка сразу после ссылки на изображение начинающаяся со слов "Рис...") сделать обычным текстом (не заголовком) и выделить курсивом: *текст подписи* 

**Задачи постобработки которые нельзя решить с помощью скрипта возложить на постобработку с помощью AI**
### Постобработка с помощью AI
1. Для пост обработки использовать AI от провайдера provod. Токен брать из .env + dotenv. Так же должен быть задан провайдер для резервной модели.
2. В качестве моделей AI использовать основной моделью: gemini-3.5-flash, резервной: claud-sonet-5
3. Задание вида провайдеров, типа моделей должны задаваться из файла конфигурации create_markdown_config.yaml
4. Использование AI обработки должно задаваться параметром запуска скрипта
5. Промт для AI должен браться из create_markdown_config.yaml. Взять за основу create_markdown_config.yaml из проекта Create_markdown

## 3. Ожидаемый результат
1. В папке заданной как выходная Markdown/<имя_входного_файла> должны находиться итоговый файл <имя_входного_файла>.md, папка image/ содержащая изображения на которые есть ссылки в итоговом .md
2. Все промежуточные файлы генерируемые Vision OCR и скриптами постобработки должны быть перемещены в папку исходного файла(папки) в подпапку tmp/<имя_входного_файла>.
3. Лог работы должен находится в папке исходного файла(папки) в подпапке tmp/Create_Markdown_VisionOCR.log
